TROUBLESHOOTING
===============

Problem: Still seeing 500 errors
Solution:
  1. Clear browser cache: Ctrl+Shift+Delete
  2. Delete frontend/.next folder
  3. Restart services
  4. Open http://localhost:3000 again

Problem: Port already in use
Solution:
  1. Find what's using the port:
     netstat -ano | findstr :3000
  2. Kill the process:
     taskkill /PID <PID> /F
  3. Restart services

Problem: Database connection error
Solution:
  1. Make sure PostgreSQL is running
  2. Check DB settings in backend/.env
  3. Should be: DB_HOST=localhost, DB_PORT=5432

Problem: API calls failing
Solution:
  1. Verify backend is running on 3001:
     netstat -ano | findstr :3001
  2. Check frontend/.env.local
  3. Should have: NEXT_PUBLIC_API_URL=http://localhost:3001
