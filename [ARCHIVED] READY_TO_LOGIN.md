## 🆘 Having Issues?

### Can't Login?
```
Issue: "Cannot reach server"
✓ Make sure backend is running on port 3001
✓ Make sure frontend is running on port 3000
✓ Check http://localhost:3001/api/auth/login works

Issue: "Invalid credentials"
✓ Check username exactly (case-sensitive)
✓ Check password exactly (case-sensitive)
✓ Verify CAPS LOCK is off
✓ Ensure user account exists

Issue: "User not found"
✓ Login as admin first
✓ Create the user in Users section
✓ Then try new credentials
```

### Quick Fix
```
If you get any error:
1. Refresh page (Ctrl+R or Cmd+R)
2. Try again with credentials
3. If persists, check server is running:
   - Backend should show: http://localhost:3001/api
   - Frontend should show: http://localhost:3000
```
