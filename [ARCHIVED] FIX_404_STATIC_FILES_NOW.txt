================================================================================

PROBLEM:
  Refused to apply style from 'http://127.0.0.1:3000/_next/static/css/...'
  because its MIME type ('text/html') is not a supported stylesheet MIME type

ROOT CAUSE:
  Frontend .next cache is stale - needs to be cleared and rebuilt

SOLUTION:
  Delete .next folder and restart frontend dev server

================================================================================
                        ⚡ QUICK FIX (1 MINUTE)
================================================================================

STEP 1: Stop Frontend
  If you have frontend running in terminal, press: Ctrl+C
  Wait for it to fully stop (2-3 seconds)

STEP 2: Clear Cache
  cd "c:\Users\Milion's\Desktop\Alem Trading\alem-crm-system\frontend"
  
  Delete the .next folder manually:
  - In Windows Explorer, go to frontend folder
  - Delete the ".next" folder if you see it
  
  OR run this command:
  Remove-Item -Recurse -Force .next

STEP 3: Restart Frontend
  Still in frontend folder, run:
  npm run dev -- --hostname 127.0.0.1

STEP 4: Wait for Build
  Wait 10-15 seconds for Next.js to rebuild
  You should see: "ready - started server on 0.0.0.0:3000"

STEP 5: Test
  http://127.0.0.1:3000
  Should now load without MIME type errors ✅

================================================================================
                      🎯 WHY THIS HAPPENS
================================================================================

Next.js caches the compiled app in the .next folder.

After code changes, the cache becomes stale.

The browser tries to load old cached assets, gets 404 errors, and receives
HTML error pages instead of CSS/JS files.

Solution: Delete the cache, rebuild fresh.
