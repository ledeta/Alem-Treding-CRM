TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"No purchase history available"
  → Customer name doesn't match in transactions
  → Check Excel for exact name match (case-sensitive)
  → Make sure to import customers FIRST, then transactions

Upload failed
  → Verify Excel columns: Customer Name, Item Name, Qty, Price, Sold By, Branch, Date
  → Ensure numeric fields are numbers, not text
  → Try with sample data from TRANSACTION_IMPORT_GUIDE.md

Items not updating after import
  → Refresh browser (Ctrl+F5)
  → Close customer profile and reopen
  → Check browser console (F12 → Console tab) for errors
