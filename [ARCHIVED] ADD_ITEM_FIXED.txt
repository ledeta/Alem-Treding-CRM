                        HOW IT WORKS INTERNALLY
================================================================================

When You Click "➕ Add Item":
  1. onClick handler triggers setShowAddModal(true)
  2. Modal component renders (conditionally)
  3. Dark overlay appears (prevents background interaction)
  4. Form modal centered on screen
  5. All form fields ready for input

When You Fill Form & Click "Add Item":
  1. handleAddItem() function executes
  2. Validates Name and SKU (required fields)
  3. Creates Item object with calculations
  4. Adds to items array
  5. Updates filteredItems array
  6. Calculates new statistics
  7. Saves to localStorage['items_data']
  8. Resets form
  9. Closes modal (setShowAddModal(false))
  10. Shows success alert

When Data Loads (Page Refresh):
  1. useEffect runs on component mount
  2. Check localStorage for 'items_data'
  3. If found: Parse and use (fast)
  4. If not found: Call itemsService.getWithCalculations()
  5. Ensure data is array
  6. Calculate statistics
  7. Update all state variables
  8. Set loading = false
  9. Page renders with data

Result: Fast, reliable, offline-capable app
