📋 EXCEL FILE FORMAT
─────────────────────────────────────────────────────────────────────────────────

✅ SUPPORTED:
  • .xlsx (Excel 2007+)
  • .xls (Excel 97-2003)
  • .csv (Comma-separated)

⚠️ IMPORTANT:
  • Column B MUST contain customer names
  • First row can be headers
  • No special characters required
  • Duplicates auto-removed
  • Empty cells auto-skipped

✅ VALID EXAMPLE:
  ┌────┬─────────────────┬──────┐
  │ A  │ B               │ C    │
  ├────┼─────────────────┼──────┤
  │ ID │ Customer Name   │ Type │
  │ 1  │ Ahmed Hassan    │ ...  │
  │ 2  │ Fatima Ali      │ ...  │
  │ 3  │ Mohammed Ismail │ ...  │
  └────┴─────────────────┴──────┘

❌ INVALID:
  • Column A has names (won't work)
  • Column B is empty
  • File is .txt or .pdf
  • File is corrupted

🐛 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────────

❓ File not accepted?
   → Check: .xlsx, .xls, or .csv format
   → Fix: Use Excel or convert to these formats

❓ No customers appear?
   → Check: Customer names in Column B
   → Fix: Put names in Column B, not column A

❓ Upload fails?
   → Check: Backend running at http://localhost:3001
   → Fix: Start backend: npm run start:dev

❓ Search not working?
   → Check: Customers uploaded successfully
   → Fix: Try uploading again

❓ Modal not opening?
   → Check: Click on customer card
   → Fix: Refresh page and try again
