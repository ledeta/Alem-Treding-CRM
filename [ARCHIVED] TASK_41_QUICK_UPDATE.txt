🔄 BUTTON BEHAVIORS
═════════════════════════════════════════════════════════════════════════════

View Button (Blue):
  • Shows read-only user details
  • Click to view, close to dismiss

Edit Button (Orange):
  • Opens editable form
  • Modify any field
  • Save Changes to update

Delete Button (Red):
  • Shows confirmation modal
  • Click "Delete User" to confirm
  • Removes user permanently

Suspend/Active Button:
  • Active user: Shows "🔒 Suspend" (Red)
  • Suspended user: Shows "✅ Active" (Green)
  • Click to toggle status
  • Updates immediately in table
  • Saves to localStorage
