Before You Deploy:
  [ ] Have Render account (or create one at https://render.com)
  [ ] GitHub account authorized with Render
  [ ] Read one of the deployment guides
  [ ] Have your service name chosen (e.g., alem-crm-frontend)

During Deployment:
  [ ] Create Web Service on Render
  [ ] Connect GitHub repository (Alem-Treding)
  [ ] Set build command: npm install && npm run build
  [ ] Set start command: npm run start
  [ ] Add environment variables (NODE_ENV, NEXT_PUBLIC_API_URL)
  [ ] Click "Create Web Service"
  [ ] Wait for green "Live" badge

After Deployment:
  [ ] Visit your app URL
  [ ] Test login with credentials
  [ ] Test creating payment request
  [ ] Test uploading Excel file
  [ ] Test admin approvals
  [ ] Verify all features work

                      💡 HELPFUL TIPS
═══════════════════════════════════════════════════════════════════════════════

✨ Quick Tips:
  • First build takes 3-5 minutes
  • Subsequent builds: 2-3 minutes
  • Free tier auto-pauses after 15 min inactivity
  • Wakes up automatically on request
  • Takes 30-60 seconds to wake up

⚡ Speed Tips:
  • Most of time is build, not deployment
  • Watch Render logs during build
  • Code changes auto-deploy on git push
  • No need to restart anything manually

🔧 Troubleshooting Tips:
  • Check logs if build fails
  • Hard refresh if page shows blank
  • Check environment variables are set
  • Verify GitHub repo is accessible
  • Try "Redeploy" button if stuck
