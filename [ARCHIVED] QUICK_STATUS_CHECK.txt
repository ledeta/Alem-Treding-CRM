═══════════════════════════════════════════════════════════════════════════════
                         🔧 TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

Issue: Page shows 404 errors for static assets
  → Solution: Clear .next folder and restart dev server
  → Command: Delete folder: frontend/.next
  → Then: npm run dev

Issue: Excel file doesn't display after upload
  → Check: Browser console for errors
  → Check: localStorage data exists
  → Try: Refresh page and view upload history

Issue: Payment requests not showing in Admin Approvals
  → Check: localStorage has 'payment_requests' data
  → Check: Admin user is logged in correctly
  → Try: Hard refresh (Ctrl+Shift+R)

Issue: Currency formatting not applied
  → Check: Column name contains "amount" or "price"
  → Check: Data type is number (not string)
  → Example: {Amount: 1000} → displays as "1,000 ับር"
