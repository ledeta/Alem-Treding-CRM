================================================================================
                        COMMON QUESTIONS
================================================================================

Q: Why is data all showing zeros?
A: It's fresh data! Add items and transactions to see numbers.

Q: Do I need a backend?
A: No! Frontend works completely offline with mock data.
   Backend can be added later if needed.

Q: Where does my data get saved?
A: In browser's localStorage. Persists during session.
   Clear browser data to reset.

Q: Can I use on phone/tablet?
A: Yes! Responsive design works on all devices.

Q: How do I add more mock data?
A: Use the ➕ buttons in each section to add items.

Q: What if I break something?
A: Refresh page (Ctrl+F5) to reload with original data.

Q: Can I export data?
A: Not yet, but that's easy to add.

Q: Is it secure?
A: Yes! Uses localStorage for persistence.
   Production deployment needs security review.

Q: What's the currency?
A: Ethiopian Birr (ብር)
   Can be changed in settings later.

Q: Can I customize colors?
A: Yes! CSS variables in GlobalStyles.
