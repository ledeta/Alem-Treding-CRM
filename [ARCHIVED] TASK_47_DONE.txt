💻 HOW IT WORKS

When user creates a payment request in Sales:
  1. Request saved to localStorage['payment_requests']
  
When admin opens Approvals page:
  2. Page loads and fetches:
     - MOCK_APPROVALS (existing data)
     - payment_requests (user created requests)
  3. Converts payment_requests to Approval format
  4. Merges both arrays
  5. Displays combined list
  
When admin clicks Approve or Reject:
  6. Status updated in memory
  7. Updated list persisted to localStorage
  8. Status survives page refresh
