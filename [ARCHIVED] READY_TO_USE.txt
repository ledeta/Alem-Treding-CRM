🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Still seeing 404 on http://localhost:3001?
  1. Hard refresh browser: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  2. Clear browser cache: Ctrl+Shift+Delete
  3. Close all browser windows and reopen
  4. Try in Incognito/Private window

Login page not loading?
  1. Check both servers are running (see terminal output)
  2. Verify backend shows: "Server running on port 3001"
  3. Verify frontend shows: "Ready in Xs"

Excel upload not working?
  1. Make sure Excel file is .xlsx or .xls format
  2. Check all required columns are present
  3. Verify data is in correct format (numbers for quantity/price)
  4. Check browser console (F12) for error messages

Cannot login?
  1. Verify you're using correct username and password
  2. Check password in 🔓_LOGIN_NOW.txt
  3. Try different browser or private window
  4. Check database is seeded (see backend terminal)
