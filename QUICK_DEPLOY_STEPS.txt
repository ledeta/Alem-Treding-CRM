ALEM TRADING CRM - RENDER DEPLOYMENT
Quick Start (5 Minutes)
==========================================

STEP 1: Prepare Your Project (2 minutes)
----------------------------------------
1. Open Command Prompt / PowerShell
2. Navigate to project:
   cd C:\Users\Milion's\Desktop\Alem-Treding-main

3. Create backend .env file:
   - Copy backend/.env.example to backend/.env
   - Edit backend/.env and fill in:
     * JWT_SECRET (any random 32+ char string)
     * DATABASE_URL (will auto-populate from Render)

4. Create frontend .env.local file:
   - Copy frontend/.env.example to frontend/.env.local
   - Set NEXT_PUBLIC_API_URL=https://alem-crm-backend.onrender.com

5. Push to GitHub:
   git add .
   git commit -m "Render deployment ready"
   git push -u origin main


STEP 2: Create Render Account (1 minute)
----------------------------------------
1. Go to https://render.com
2. Sign up with GitHub
3. Authorize Render to access your repos


STEP 3: Deploy Services (2 minutes)
-----------------------------------

CREATE POSTGRESQL DATABASE:
1. Click "New +" → "PostgreSQL"
2. Name: alem-crm-db
3. Database: alem_crm
4. Region: Select closest to you
5. Plan: Standard ($15/month)
6. Create
7. WAIT 2-3 minutes for database to be ready
8. NOTE the connection string displayed


CREATE BACKEND SERVICE:
1. Click "New +" → "Web Service"
2. Select your GitHub repo
3. Settings:
   - Name: alem-crm-backend
   - Root Directory: backend
   - Dockerfile Path: Dockerfile
   - Region: Same as database
4. Environment Variables (Add these):
   NODE_ENV = production
   PORT = 3001
   DATABASE_URL = (paste the PostgreSQL connection string)
   JWT_SECRET = your_random_32_char_string_here
   API_URL = https://alem-crm-backend.onrender.com
   FRONTEND_URL = https://alem-crm-frontend.onrender.com
   CORS_ORIGIN = https://alem-crm-frontend.onrender.com
5. Create Web Service
6. WAIT for build to complete (3-5 minutes)
7. Check "Live" status in dashboard


CREATE FRONTEND SERVICE:
1. Click "New +" → "Web Service"
2. Select your GitHub repo
3. Settings:
   - Name: alem-crm-frontend
   - Root Directory: frontend
   - Dockerfile Path: Dockerfile
   - Region: Same as backend
4. Environment Variables (Add these):
   NODE_ENV = production
   NEXT_PUBLIC_API_URL = https://alem-crm-backend.onrender.com
   PORT = 3000
5. Create Web Service
6. WAIT for build to complete (3-5 minutes)
7. Check "Live" status in dashboard

TROUBLESHOOTING
===============

Problem: Build fails with "Node version error"
Solution: Render uses Node 20 by default - should work. Check logs.

Problem: Database connection fails
Solution: Wait 3-5 minutes for PostgreSQL to fully initialize.
Then copy connection string to DATABASE_URL env var.

Problem: CORS error in browser
Solution: Make sure CORS_ORIGIN env var matches frontend URL exactly.

Problem: Permissions not showing as checked
Solution: This is by design. All 15 permissions auto-assigned to new users.
Check localStorage → users_data in browser DevTools.

Problem: Can't login with created account after refresh
Solution: Uses localStorage. If cleared, data is lost. 
Default accounts (admin, sales, million) always work.

Problem: Frontend shows blank page
Solution: Check NEXT_PUBLIC_API_URL is set correctly in environment.
Check browser console for errors (F12).
