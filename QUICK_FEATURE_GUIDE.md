## 🚀 Common Tasks

### Add New Customer
1. Go to Customers
2. Click "+ Add New"
3. Enter customer details
4. Set credit limit
5. Save

### Record Transaction
1. Go to Transactions
2. Click "+ New Transaction"
3. Select customer
4. Enter amount
5. Choose transaction type
6. Save and auto-notify

### Process Payment
1. Go to Payments
2. Click "+ New Payment"
3. Select customer
4. Enter amount
5. Choose payment method
6. Generate receipt

### Send Message
1. Go to Chat
2. Select recipient
3. Type message
4. Send (instant delivery)

### Create Approval Request
1. Go to Approvals
2. Click "+ New Request"
3. Select type & amount
4. Add description
5. Submit for approval
