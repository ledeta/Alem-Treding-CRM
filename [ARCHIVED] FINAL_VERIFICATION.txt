TECHNICAL SPECIFICATIONS
================================================================================

Upload Endpoint:
  Method: POST
  URL: /api/transactions/import/sales
  Authentication: NONE (@Public)
  Content-Type: multipart/form-data
  Field Name: file
  Accepted Types: .xlsx
  Max File Size: 10MB

Database Operations:
  Creates: Customers (if missing)
  Creates: Items (if missing)
  Creates: Transactions
  Updates: Stock levels

Response Format:
  Status: 201 Created (success)
  Body: JSON with summary statistics
  Fields: totalRows, successCount, failCount, parseErrors, importErrors, 
          categorySummary, branchSummary, salesPersonSummary, timestamp

KNOWN LIMITATIONS
================================================================================

  • Only Excel files (.xlsx format)
  • Uses first sheet only
  • Headers must be in row 1
  • Data starts from row 2
  • No formula support (values only)
  • No merged cells support
  • File limit: 10MB
