5-MINUTE DEPLOYMENT OVERVIEW
═══════════════════════════════════════════════════════════════════════════

1. Go to: https://dashboard.render.com
2. Connect GitHub (Alem-Treding repository)
3. Deploy Backend:
   - New Web Service
   - Root Directory: backend
   - Build: npm install && npm run build
   - Start: node dist/main.js
4. Deploy Frontend:
   - New Web Service
   - Root Directory: frontend
   - Build: npm install && npm run build
   - Start: npm run start
5. Create PostgreSQL Database:
   - New PostgreSQL service
   - Database name: alem_crm
6. Set Environment Variables (see guide)
7. Verify by testing /api/health endpoint

═══════════════════════════════════════════════════════════════════════════
ENVIRONMENT VARIABLES NEEDED
═══════════════════════════════════════════════════════════════════════════

Backend:
  NODE_ENV=production
  PORT=3001
  DATABASE_URL=postgresql://user:password@host:5432/alem_crm
  JWT_SECRET=[generate random 32+ character string]

Frontend:
  NODE_ENV=production
  NEXT_PUBLIC_API_URL=https://your-backend-url.onrender.com/api

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

If backend fails to start:
  1. Check DATABASE_URL is correct
  2. Verify PostgreSQL service is running
  3. Check JWT_SECRET is set
  4. Review Render logs

If frontend can't connect:
  1. Verify NEXT_PUBLIC_API_URL is correct
  2. Test backend /api/health endpoint
  3. Check CORS is enabled
  4. Clear browser cache

If payment feature doesn't work:
  1. Verify backend is running
  2. Check @Public() decorator on endpoint
  3. Verify database connectivity
  4. Check browser console for errors

See detailed troubleshooting in:
  - RENDER_DEPLOYMENT_GUIDE.md
  - 🚀_READY_TO_DEPLOY_RENDER.txt
