================================================================================
  ⚠️ IMPORTANT NOTES
================================================================================

1. PREREQUISITES ARE MANDATORY
   - Cannot proceed without JDK and Android Studio installed
   - Must set environment variables correctly

2. ENVIRONMENT VARIABLES CRITICAL
   - JAVA_HOME must point to JDK installation
   - ANDROID_HOME must point to Android SDK
   - Restart terminal/IDE after setting

3. BACKUP SIGNING KEYSTORE
   - When creating release build, backup keystore file
   - Losing it means cannot update app on Play Store
   - Create strong password

4. FRONTEND BUILD REQUIRED
   - Always run "npm run build" before syncing to Android
   - Capacitor copies from frontend/out directory
   - Must be done each time you update frontend

5. API CONNECTION
   - App connects to https://alem-crm-api.onrender.com
   - Verify backend is accessible before testing
   - Check network connectivity if app fails to load
