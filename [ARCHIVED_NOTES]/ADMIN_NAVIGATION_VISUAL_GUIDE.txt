│ RESPONSIVE BREAKPOINTS                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

  Mobile (< 768px)
  ├─ Vertical stack layout
  ├─ Horizontal tab navigation
  ├─ Touch-friendly (48px min height)
  └─ Grid: 1-2 columns

  Tablet (768px - 1200px)
  ├─ Collapsible sidebar
  ├─ Horizontal tabs
  ├─ Medium spacing
  └─ Grid: 2-3 columns

  Desktop (> 1200px)
  ├─ Full sidebar visible
  ├─ Admin nav bar
  ├─ Expanded descriptions
  └─ Grid: 4 columns


┌─────────────────────────────────────────────────────────────────────────────┐
│ USAGE EXAMPLE                                                               │
└─────────────────────────────────────────────────────────────────────────────┘

  Step 1: Log in as Admin
  ─────────────────────
  URL: http://127.0.0.1:3000/login
  Username: admin
  Password: Admin@2024!

  Step 2: Navigate to Admin
  ─────────────────────
  URL: http://127.0.0.1:3000/admin
  (Navigation appears automatically)

  Step 3: Choose Display Mode
  ─────────────────────
  Click "List View" or "Grid View" button
  to toggle between variants

  Step 4: Click Navigation Item
  ─────────────────────
  Select desired section (Dashboard, Customers, etc.)
  Page automatically navigates and updates
