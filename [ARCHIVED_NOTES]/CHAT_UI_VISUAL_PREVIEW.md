## Color Scheme Applied

**Background Gradient**: 
```css
from-white via-violet-50 to-purple-50
```

**Own Messages**:
```css
bg-gradient-to-br from-violet-600 to-purple-600 text-white
```

**Other Messages**:
```css
bg-[color]-100 text-[color]-900 border border-violet-200
```

**Accents**:
```css
text-violet-600 (default)
text-blue-600 (manager)
text-pink-600 (team lead)
etc.
```
