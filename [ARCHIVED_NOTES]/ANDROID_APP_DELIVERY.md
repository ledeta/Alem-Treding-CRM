## 🚀 How to Install

### Option 1: Direct APK Installation (Debug)
```bash
# Prerequisites:
# - Android device or emulator
# - USB debugging enabled (for device)
# - ADB installed

# Command:
adb install -r "path/to/app-debug.apk"

# Or manually:
# 1. Copy app-debug.apk to phone
# 2. Open file manager
# 3. Tap the APK file
# 4. Allow installation
# 5. App installs
```

### Option 2: Direct APK Installation (Release)
```bash
# For distribution to users:
adb install -r "path/to/app-release.apk"

# Or share the APK file directly
```

### Option 3: Google Play Store
```
1. Use release APK (app-release.apk)
2. Go to Google Play Console
3. Create app listing
4. Upload AAB (generate first):
   .\gradlew.bat bundleRelease
5. Fill in app details
6. Submit for review (1-3 hours)
7. App appears on Play Store
```

## 📞 Troubleshooting

### Can't Install APK
```
Solution:
1. Check Android version (need 7.0+)
2. Enable "Unknown Sources" in Settings
3. Check storage space (need 100MB+)
4. Try USB debugging mode
5. Use adb install command
```

### App Won't Start
```
Solution:
1. Check internet connection
2. Try killing and restarting
3. Clear app cache: Settings → Apps → ALEM → Clear Cache
4. Reinstall the app
5. Check backend is running
```

### Can't Login
```
Solution:
1. Verify username (exact case)
2. Check both passwords are correct
3. Try different account (sales vs admin)
4. Ensure backend is reachable
5. Check network connectivity
```

### Slow Performance
```
Solution:
1. Check available storage (clear cache if low)
2. Check internet speed
3. Restart phone
4. Close other apps
5. Update Android if available
```
