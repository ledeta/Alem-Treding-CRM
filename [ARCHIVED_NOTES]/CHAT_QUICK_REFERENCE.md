# 💬 Chat Section - Quick Reference Guide

## 🎯 Quick Start

**Access Chat**: Navigate to `/chat` from the main navigation menu

## 📋 Features at a Glance

| Feature | How to Use | Shortcut |
|---------|-----------|----------|
| **Send Message** | Type in text area and click Send | `Enter` |
| **New Line** | Add line within message | `Shift + Enter` |
| **Edit Message** | Hover over your message, click pencil icon | - |
| **Delete Message** | Hover over your message, click trash icon | - |
| **Search Messages** | Use search box in header | Filter by text |
| **View Member Info** | Click user's name or avatar | See user color |

## 🎨 User Color Guide

Each team member has a unique color for easy identification:

```
Support Team   → 🟣 Violet-Purple    (Primary)
Manager        → 🔵 Blue-Cyan        (Secondary)
Team Lead      → 💗 Pink-Rose        (Tertiary)
Other Users    → 🟢 Emerald-Teal     (Support)
                 🟠 Amber-Orange     (Alternative)
                 🟤 Indigo-Purple    (Alternative)
```

## 🚀 User Interactions

### Sending a Message
1. Click in the message input area
2. Type your message
3. Press `Enter` or click the "Send" button
4. Message appears on the right side with your user color

### Editing a Message
1. Hover over your message (right side)
2. Click the pencil (✏️) icon
3. Edit the text in the edit box
4. Click "Save" to confirm or "Cancel" to discard
5. Message shows "(edited)" indicator

### Deleting a Message
1. Hover over your message (right side)
2. Click the trash (🗑️) icon
3. Message is immediately removed
4. Cannot be recovered once deleted

### Searching Messages
1. Click the search box in the header
2. Type keywords to search
3. Chat filters to matching messages
4. Messages grouped by date as usual

## 🎨 Color Meanings

- **Violet/Purple** (Own messages) - Messages you sent appear with a gradient violet-purple background
- **Unique Color** (Other users) - Each team member has a distinct light-colored background with their initials or avatar emoji

## 📱 Mobile Tips

- On mobile, search bar is hidden to save space
- Send button shows only icon (→) instead of text
- Messages are fully responsive and readable on all screen sizes
- All features work the same on mobile and desktop

## 💡 Pro Tips

1. **Easy User Recognition**: Each colored bubble tells you who sent the message instantly
2. **Search Before Asking**: Use the search feature to find previous discussions
3. **Edit Before Delete**: You can edit messages - try that instead of deleting
4. **Date Grouping**: Messages are organized by date for easy navigation
5. **Team Coordination**: Use the chat for quick team updates and decisions

## ⚙️ System Information

- **Messages Storage**: Stored locally in browser (localStorage)
- **Message Limit**: No hard limit on message count
- **Persistence**: Messages saved automatically as you type
- **Backup**: Messages persist across browser sessions
- **Privacy**: All messages visible to all team members

## 🎯 Best Practices

✅ **DO**
- Use for team coordination and quick updates
- Search before asking duplicate questions
- Use clear, concise language
- Edit messages if needed instead of deleting and retyping
- Tag team members when discussing relevant topics

❌ **DON'T**
- Use for sensitive financial information
- Send messages without context
- Spam or use excessive capitalization
- Delete messages unnecessarily (edit instead)
- Rely on chat for critical business decisions without documentation

## 📞 Support

For issues or feature requests:

2. Document the issue clearly
3. Provide specific steps to reproduce
