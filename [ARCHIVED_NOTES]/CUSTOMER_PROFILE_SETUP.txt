================================================================================
HOW TO USE
================================================================================

1. NAVIGATE TO CUSTOMERS PAGE:
   → Go to Admin → Customers
   → You should see the new grid-based layout

2. VIEW CUSTOMER PROFILE:
   → Click on any customer card
   → Modal opens showing:
     - Full contact information
     - Account summary with balances
     - Complete transaction history
     - Filter transactions by type

3. SEND PAYMENT REQUEST:
   → Click "Payment Request" button in profile modal
   → Enter amount (or use total due)
   → Select payment method
   → Add optional notes
   → Click "Send Request"
   → See success confirmation

4. FILTER TRANSACTIONS:
   → Use tabs in transaction section: All, Sale, Payment, Credit, Refund
   → Table updates automatically
   → View specific transaction types

================================================================================
API ENDPOINTS USED
================================================================================

✅ GET /api/customers?page=1&limit=1000
   - Fetches all customers for grid display

✅ GET /api/transactions/customer/:id?page=1&limit=100
   - Fetches transaction history for specific customer
   - Displays in profile modal

📝 POST /api/payment-requests (Ready for backend integration)
   - Expects: { customerId, amount, method, notes, dueDate }
   - Returns: { id, status, message }

TROUBLESHOOTING
================================================================================
