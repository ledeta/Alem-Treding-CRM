============

================================================================================

Go to: https://github.com/settings/tokens

Steps:
1. Click "Generate new token (classic)"

COMMAND 2: REMOVE SSH REMOTE (Quick Fix)
────────────────────────────────────────
Open PowerShell and run:

COMMAND 3: PUSH WITH TOKEN (The Magic)
──────────────────────────────────────
In PowerShell, run this (replace YOUR_TOKEN with actual token):
