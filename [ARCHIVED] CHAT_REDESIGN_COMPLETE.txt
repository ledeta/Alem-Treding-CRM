🎯 USAGE INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════

  ACCESS THE CHAT:
  1. Open browser to http://localhost:3000
  2. Login with credentials
  3. Navigate to "Chat" from menu
  4. Start sending messages

  SEND MESSAGE:
  1. Type in the message input area
  2. Press Enter or click Send button
  3. Message appears on right side with violet gradient

  EDIT MESSAGE:
  1. Hover over your message
  2. Click the pencil (✏️) icon
  3. Edit and click Save

  DELETE MESSAGE:
  1. Hover over your message
  2. Click the trash (🗑️) icon
  3. Message is immediately removed

  SEARCH MESSAGES:
  1. Click search box in header
  2. Type keywords
  3. Messages filter automatically
