## 🆘 TROUBLESHOOTING

### APK Won't Upload
- **Issue:** "File too large"
- **Solution:** APK is only 4.1 MB, should upload fine
- Check file integrity: verify file is not corrupted
- Try uploading again

### Emulator Won't Boot
- **Issue:** "Timeout waiting for device"
- **Solution:** Wait longer (can take 60+ seconds)
- Try different Android version
- Try different device model

### App Won't Install
- **Issue:** "Installation failed"
- **Solution:** Check APK is valid (it is)
- Try uploading again
- Check Appetize has free minutes remaining

### Login Fails
- **Issue:** "Authentication error"
- **Solution:** Verify credentials:
  - Username: `admin` (exact case)
  - Password 1: `Admin@2024!` (with exclamation)
  - Password 2: `AdminSecure#2024` (with hash)
- Check backend is running locally

### Can't Connect to Backend
- **Issue:** "Network connection error"
- **Solution:** 
  - Backend must be running on your PC
  - Appetize runs in the cloud but connects to your local backend
  - Check Terminal 5 shows backend running
  - Check firewall allows connections

### Slow Performance
- **Issue:** "Emulator is laggy"
- **Solution:**
  - This is normal for cloud emulators
  - Try refreshing page
  - Check your internet connection
  - Try during off-peak hours
