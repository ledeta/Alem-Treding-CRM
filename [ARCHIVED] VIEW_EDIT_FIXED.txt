                         HOW TO USE NOW
================================================================================

TO VIEW AN ITEM:
  1. Go to Items page: http://localhost:3000/items
  2. Find an item in the table
  3. Click "View" button
  4. Item details page opens
  5. Click "Edit Item" or "← Back"

TO EDIT AN ITEM:
  1. Click "View" from table, then "Edit Item"
     OR
     Click "Edit" directly from table
  2. Form opens with item data pre-filled
  3. Change any fields
  4. Click "💾 Save Changes"
  5. Item updates in table
  6. Redirected to view page

TO ADD NEW ITEM WITH NEW CATEGORIES:

     ✓ Accessories

     ✓ Screen (NEW)
     ✓ Other

  5. Click "Add Item"
