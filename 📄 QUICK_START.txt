    COMPLETE_SETUP.bat

  OPTION 2: Database Only (If pgAdmin is slow)
═══════════════════════════════════════════════════════════════

Double-click this file:
    SETUP_DATABASE_SIMPLE.bat

You'll be prompted for PostgreSQL password.

═══════════════════════════════════════════════════════════════
  OPTION 3: Wait for pgAdmin
═══════════════════════════════════════════════════════════════

pgAdmin usually takes 30-60 seconds to start first time.
Once it opens:
  1. Create database: alem_crm
  2. Run SQL file: database\schema.sql

═══════════════════════════════════════════════════════════════
  AFTER DATABASE IS CREATED
═══════════════════════════════════════════════════════════════

Then run these commands in Command Prompt:

1. Install NestJS CLI:
   cd backend
   npm install --save-dev @nestjs/cli

2. Install Frontend:
   cd ..\frontend
   npm install --legacy-peer-deps

3. Start Backend:
   cd ..\backend
   npm run start:dev

4. Start Frontend (new terminal):
   cd frontend
   npm run dev

5. Open browser:
   http://localhost:3000
