STEP 2: CLEAR BROWSER CACHE & COOKIES
───────────────────────────────────────────────────────────────────────────

FOR GOOGLE CHROME:
  1. Press: Ctrl + Shift + Delete
     (This opens "Clear Browsing Data")
  
  2. Time range:
     → Click dropdown that says "Time range"
     → Select: "All time"
  
  3. Check these boxes:
     ☑ Cookies and other site data
     ☑ Cached images and files
     ☑ (uncheck "Browsing history" if you want to keep it)
  
  4. Click: "Clear data" button (blue button)
  
  5. Wait for it to complete (usually 2-5 seconds)

FOR FIREFOX:
  1. Press: Ctrl + Shift + Delete
     (This opens "Clear Recent History")
  
  2. Time range:
     → Select: "Everything"
  
  3. Details:
     → Check: "Cookies"
     → Check: "Cache"
  
  4. Click: "Clear Now"

FOR EDGE:
  1. Press: Ctrl + Shift + Delete
  
  2. Clear browsing data:
     → Time range: "All time"
     → Check: "Cookies and other site data"
     → Check: "Cached images and files"
  
  3. Click: "Clear now"

💡 WHY THIS HAPPENS
───────────────────────────────────────────────────────────────────────────

Browser cache stores:
• Old HTML pages
• Old CSS files
• Old JavaScript files

When you reload, browser shows OLD files instead of new ones.

The "hard refresh" (Ctrl+Shift+R) forces browser to:
1. Ignore cache
2. Download fresh files from server
3. Show the NEW 3-button navigation
