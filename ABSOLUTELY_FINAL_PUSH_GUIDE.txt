STEP 1: GET YOUR GITHUB PERSONAL ACCESS TOKEN (2 minutes)
================================================================================

Open your browser and go to:
https://github.com/settings/tokens

Follow these EXACT steps:

1. Click: "Generate new token"
2. Click: "Generate new token (classic)"
3. Name: AlemTredintDeploy
4. Expiration: 90 days
5. Scope: Scroll down and check ONLY "repo"
6. Scroll to bottom and click: "Generate token"
7. COPY the token (the long string that appears)
   - Looks like: ghp_abc123def456ghi789jkl012mno345pqr678

IMPORTANT: You only see this token ONCE. Copy it now!


STEP 2: RUN THE PUSH SCRIPT (2 minutes)
================================================================================

Open PowerShell in your project directory and run:

.\PUSH_WITH_TOKEN.ps1

The script will:
1. Ask you to paste your token
2. Paste the token from Step 1
3. Script pushes all code
4. Shows success message
