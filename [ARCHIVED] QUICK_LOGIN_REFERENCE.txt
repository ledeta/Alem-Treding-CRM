📞 HELP & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Can't login?
   • Check username spelling (case-sensitive)
   • Verify CAPS LOCK is off
   • Try copying/pasting password
   • Ensure user account is Active (not suspended)

Forgot password?
   • Contact your admin to reset
   • Admin can reset from Users menu

Need new account?
   • Contact admin to create account
   • Provide: Full name, email, phone, desired role

🌐 API TOKEN USAGE (For Developers)
═══════════════════════════════════════════════════════════════════════════

Get Token:
   curl -X POST http://localhost:3001/auth/login \
     -H "Content-Type: application/json" \
     -d '{"username":"admin","password":"Admin123!"}'

Use Token:
   curl -X GET http://localhost:3001/api/customers \
     -H "Authorization: Bearer {accessToken}"
