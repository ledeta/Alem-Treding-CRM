✅ WHY THIS HAPPENS
═════════════════════════════════════════════════════════════════════════════

✓ Normal behavior when code changes
✓ Next.js recompiles webpack chunks
✓ Browser cache has old file references
✓ Files not found until recompilation completes
✓ Temporary - resolves automatically


✅ HOW TO PREVENT
═════════════════════════════════════════════════════════════════════════════

1. Use incognito/private browsing (no cache)
2. Hard refresh (Ctrl+Shift+Delete) after changes
3. Wait 5-10 seconds for recompilation
4. Check browser console - errors disappear after recompilation
