💡 HOW IT WORKS:

JavaScript Map iterates through all transactions and:
  1. Creates key = item name
  2. If key doesn't exist → add new entry
  3. If key exists → add to existing totals
  4. Returns array sorted by spending (highest first)

Result: Zero duplicates, clean aggregated view
