METHOD 1: LOCAL DEVELOPMENT (Fastest - 5 minutes)
═════════════════════════════════════════════════

BEST FOR: Immediate testing, development, demo

REQUIREMENTS:
├─ Windows/Mac/Linux
├─ Node.js 18+ (from nodejs.org)
├─ PostgreSQL 18+ (from postgresql.org)
└─ Git (optional)

INSTALLATION STEPS:

Step 1: Start PostgreSQL
────────────────────
Windows:
  Option A: Services → Start "postgresql-x64-18"
  Option B: Command line → pg_ctl -D "C:\Program Files\PostgreSQL\18\data" start
  Option C: Double-click → START_POSTGRESQL.bat

Step 2: Install Backend Dependencies
──────────────────────────────────
  1. Open Command Prompt/PowerShell
  2. cd "c:\Users\Milion's\Desktop\Alem Trading\alem-crm-system\backend"
  3. npm install
  4. npm run start:dev
  5. Wait for: "✅ Server running on port 3001"

Step 3: Install Frontend Dependencies
──────────────────────────────────
  1. Open NEW Command Prompt/PowerShell
  2. cd "c:\Users\Milion's\Desktop\Alem Trading\alem-crm-system\frontend"
  3. npm install
  4. npm run dev
  5. Wait for: "- ready started server on 0.0.0.0:3000"

Step 4: Access Your App
──────────────────────
  1. Open browser
  2. Go to: http://localhost:3000
  3. Login: admin / Admin@2024! / AdminSecure#2024
  4. Done! ✅

TROUBLESHOOTING:
├─ "Port 3000 in use?" → Kill process: netstat -ano | findstr ":3000"
├─ "PostgreSQL error?" → Check: psql -U postgres -c "SELECT 1"
└─ "npm not found?" → Install Node.js from nodejs.org

UPTIME: ∞ (as long as terminals are open)

METHOD 2: DOCKER DEPLOYMENT (Recommended - 3 minutes)
════════════════════════════════════════════════════

BEST FOR: Production, consistency, easy scaling

REQUIREMENTS:
├─ Docker (from docker.com)
├─ Docker Compose
└─ ~2GB available disk space

INSTALLATION STEPS:

Step 1: Install Docker
─────────────────────
  1. Go to: https://docker.com/products/docker-desktop
  2. Download for your OS (Windows/Mac/Linux)
  3. Install and restart computer
  4. Verify: Run "docker --version" in terminal

Step 2: Navigate to Project
──────────────────────────
  1. Open terminal/PowerShell
  2. cd "c:\Users\Milion's\Desktop\Alem Trading\alem-crm-system"
  3. Verify docker-compose.yml exists (it should)

Step 3: Start All Services
──────────────────────────
  Run: docker-compose up -d

  Wait for output:
  ├─ Creating alem-postgres ... done
  ├─ Creating alem-backend ... done
  └─ Creating alem-frontend ... done

Step 4: Access Your App
──────────────────────
  1. Wait 10 seconds for services to start
  2. Open browser
  3. Go to: http://localhost:3000
  4. Login: admin / Admin@2024! / AdminSecure#2024
  5. Done! ✅

USEFUL COMMANDS:
├─ View logs: docker-compose logs -f
├─ Stop all: docker-compose down
├─ Restart: docker-compose restart
└─ Remove all: docker-compose down -v

UPTIME: Persistent (survives reboots if configured)

METHOD 3: RENDER.COM DEPLOYMENT (Free - 10 minutes)
═══════════════════════════════════════════════════

BEST FOR: Cloud hosting, auto-scaling, free tier available

REQUIREMENTS:
├─ GitHub account (github.com - free)
├─ Render.com account (render.com - free tier)
└─ This codebase pushed to GitHub

INSTALLATION STEPS:

Step 1: Push Code to GitHub
───────────────────────────
  1. Create repository: github.com/new
  2. Name it: alem-trading-crm
  3. Make it PUBLIC
  4. Copy code to local folder:
     git init
     git add .
     git commit -m "Initial commit"
     git remote add origin https://github.com/YOUR_USERNAME/alem-trading-crm.git
     git push -u origin main

Step 2: Connect to Render
────────────────────────
  1. Go to: https://render.com
  2. Sign up (or login if you have account)
  3. Click "New +"
  4. Select "Web Service"
  5. Connect GitHub account
  6. Select repository: alem-trading-crm
  7. Click "Connect"

Step 3: Configure Backend
────────────────────────
  1. Name: alem-crm-backend
  2. Environment: Node
  3. Build command: cd backend && npm install
  4. Start command: cd backend && npm run start:prod
  5. Add environment variables:
     - NODE_ENV=production
     - DATABASE_URL=(Render will provide)
  6. Click "Create Web Service"
  7. Wait ~5-10 minutes for deployment

Step 4: Configure Frontend
──────────────────────────
  1. Add another service
  2. Name: alem-crm-frontend
  3. Environment: Node
  4. Build command: cd frontend && npm install && npm run build
  5. Start command: cd frontend && npm start
  6. Add environment variable:
     - NEXT_PUBLIC_API_URL=https://alem-crm-backend.onrender.com
  7. Click "Create Web Service"
  8. Wait ~5-10 minutes for deployment

Step 5: Access Your App
──────────────────────
  1. Go to Render dashboard
  2. Click frontend service
  3. Find the URL (e.g., alem-crm-frontend.onrender.com)
  4. Open in browser
  5. Login: admin / Admin@2024! / AdminSecure#2024
  6. Done! ✅

NOTES:
├─ Free tier: Services sleep after 15 min inactivity
├─ Premium: Always-on for $7/month per service
├─ Database: Create PostgreSQL on Render separately
└─ Custom domain: $2-4/month

UPTIME: As per plan (free = intermittent, paid = 99.9%)

METHOD 4: ANDROID APP INSTALLATION (2 minutes)
════════════════════════════════════════════════

BEST FOR: Mobile testing, production release

REQUIRES:
├─ Android device OR BlueStacks emulator
├─ APK file (already built - in android-app folder)
└─ ~50MB free space

TESTING ON BLUESTACKS:

Step 1: Get the APK
──────────────────
  Path: c:\Users\Milion's\Desktop\Alem Trading\alem-crm-system\
        android-app\android\app\build\outputs\apk\debug\app-debug.apk

Step 2: Install
──────────────
  Option A (Easiest): Drag & Drop
    1. Open BlueStacks
    2. Drag app-debug.apk into BlueStacks window
    3. Click "Install"
    4. Wait for installation

  Option B: Command Line
    1. Open Command Prompt
    2. adb connect 127.0.0.1:5555
    3. adb install -r "C:\path\to\app-debug.apk"
    4. Wait for success message

Step 3: Run App
──────────────
  1. Click ALEM Trading CRM on home screen
  2. App launches and loads
  3. See login screen
  4. Login: admin / Admin@2024! / AdminSecure#2024
  5. Use app! ✅

PRODUCTION RELEASE:

File: android-app\android\app\build\outputs\apk\release\app-release.apk

For Google Play Store:
  1. Create Google Play Developer account ($25 one-time)
  2. Create app listing
  3. Upload app-release.apk
  4. Fill in description, screenshots, permissions
  5. Submit for review (~1-2 hours approval)
  6. Go live!
