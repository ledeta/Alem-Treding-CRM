KEY CHANGES

Before: Username + Password → Login
Now: Username + Password1 → Password2 → Login

All user data includes 2 passwords now:
  password1 - Used in Step 1 (login attempt)
  password2 - Used in Step 2 (verification)

Dynamic users created in Account Management must have BOTH passwords
