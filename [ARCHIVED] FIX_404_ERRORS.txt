PROBLEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You're seeing errors like:
  ❌ GET http://localhost:3000/transactions 404 (Not Found)

Root Cause:
  • Your browser was trying to reach port 3000
  • But frontend is running on port 3001
  • And backend is on port 3001
  • Browser had cached the wrong port or old environment variables

SOLUTION (STEP BY STEP)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ STEP 1: Open Developer Tools (F12)
   Press F12 to open browser developer console

✅ STEP 2: Clear Application Cache
   • Go to "Application" tab (or "Storage" in Firefox)
   • Click "Clear site data"
   • Check all boxes
   • Click "Clear"

✅ STEP 3: Clear Local Storage
   In the Console tab, paste and run:
   ┌─────────────────────────────────────────┐
   │ localStorage.clear()                    │
   │ sessionStorage.clear()                  │
   └─────────────────────────────────────────┘

✅ STEP 4: Hard Refresh Browser
   Windows/Linux: Press Ctrl + Shift + R
   Mac:          Press Cmd + Shift + R
   Or:           Ctrl + F5

✅ STEP 5: Access Correct URL
   Go to: http://localhost:3001
   (NOT 3000)

✅ STEP 6: Login Again
   Enter your credentials to log in again

ONE-COMMAND FIX (Browser Console)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Paste this in Console (F12) and press Enter:
┌─────────────────────────────────────────────────────────────────┐
│ localStorage.clear(); sessionStorage.clear(); location.reload(); │
└─────────────────────────────────────────────────────────────────┘

This will:
  1. Clear local storage
  2. Clear session storage
  3. Reload the page
  4. Reload will pick up correct environment variables

ALTERNATIVE: Full Cache Clear
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Windows:
  1. Press Ctrl + Shift + Delete
  2. Check "Cookies and other site data"
  3. Check "Cached images and files"
  4. Click "Clear data"
  5. Go to http://localhost:3001

Mac:
  1. Chrome Menu → Preferences
  2. Privacy and Security → Clear browsing data
  3. Check "Cookies" and "Cached images"
  4. Click "Clear data"
  5. Go to http://localhost:3001
