================================================================================
PROBLEM SUMMARY
================================================================================

ERROR MESSAGE:
"Failed to load resource: the server responded with a status of 401 (Unauthorized)"

ROOT CAUSE:
The approvals page was using ONLY mock data and never sending JWT token with
API requests. The backend's JWT authentication guard rejected all requests
because they lacked the Authorization header.

AFFECTED ENDPOINT:
GET http://localhost:3001/api/approvals?page=1&limit=50

================================================================================
SOLUTION IMPLEMENTED
================================================================================

FILE MODIFIED:
✅ frontend/src/app/approvals/page.tsx

CHANGES MADE:

1. REMOVED MOCK DATA
   - Deleted hardcoded approval array with 3 sample items
   - Replaced with dynamic API fetching

2. ADDED JWT AUTHENTICATION
   - Retrieve token from localStorage
   - Include token in Authorization header on every request
   - Send with format: "Authorization: Bearer <token>"

3. IMPLEMENTED API INTEGRATION
   - Fetch data from /api/approvals?page=1&limit=50
   - Transform API response to component interface
   - Handle empty/null fields with sensible defaults

4. ADDED ERROR HANDLING
   - Check for 401 Unauthorized responses
   - Clear invalid token and redirect to login on 401
   - Display user-friendly error messages
   - Log errors to console for debugging

5. IMPLEMENTED APPROVE/REJECT
   - Send PUT requests to /api/approvals/{id}/approve
   - Include decision in request body (approved/rejected)
   - Update local state after successful API call
   - Show error alerts on failure

================================================================================
KEY CODE SECTIONS
================================================================================

1. TOKEN RETRIEVAL:
   const token = localStorage.getItem('token');
   if (!token) {
     window.location.href = '/login';
     return;
   }

2. AUTHORIZATION HEADER:
   const response = await fetch(`${API_URL}/api/approvals?page=1&limit=50`, {
     method: 'GET',
     headers: {
       'Content-Type': 'application/json',
       'Authorization': `Bearer ${token}`,  // ← THE CRITICAL FIX
     },
   });

3. 401 HANDLING:
   if (response.status === 401) {
     localStorage.removeItem('token');
     window.location.href = '/login';
     return;
   }

4. APPROVE/REJECT:
   const response = await fetch(`${API_URL}/api/approvals/${id}/approve`, {
     method: 'PUT',
     headers: {
       'Authorization': `Bearer ${token}`,
       'Content-Type': 'application/json',
     },
     body: JSON.stringify({ decision: 'approved', notes: '' }),
   });
