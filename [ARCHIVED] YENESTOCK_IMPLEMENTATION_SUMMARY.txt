DATABASE SCHEMA:
- 3 main tables: yenestock_stock, yenestock_locations, yenestock_movements
- Indexes on frequently queried fields (itemId, locationId, createdAt)
- Soft delete support (isActive boolean)
- Comprehensive audit trail with timestamps
- Foreign key relationships maintained

================================================================================
DATABASE ENTITIES
================================================================================

YeneStockInventory (yenestock_stock):
- id: INT PRIMARY KEY
- itemId: INT (Foreign Key to items table)
- locationId: INT (Foreign Key to locations table)
- currentQuantity: DECIMAL(15,2)
- minimumLevel: DECIMAL(15,2)
- maximumLevel: DECIMAL(15,2)
- reorderPoint: DECIMAL(15,2)
- warehouseCode: VARCHAR (indexed)
- batchNumber: VARCHAR
- expiryDate: TIMESTAMP
- isExpired: BOOLEAN
- hasAlert: BOOLEAN
- lowStockAlertCount: INT
- lastRestocked: TIMESTAMP
- notes: TEXT
- isActive: BOOLEAN (soft delete)
- createdAt: TIMESTAMP
- updatedAt: TIMESTAMP

StockLocation (yenestock_locations):
- id: INT PRIMARY KEY
- code: VARCHAR UNIQUE (indexed)
- warehouseName: VARCHAR
- address: VARCHAR
- city: VARCHAR
- country: VARCHAR
- isMainWarehouse: BOOLEAN
- maxCapacity: INT
- currentLoad: INT
- managerName: VARCHAR
- managerPhone: VARCHAR
- managerEmail: VARCHAR
- description: TEXT
- isActive: BOOLEAN
- createdAt: TIMESTAMP
- updatedAt: TIMESTAMP

StockMovement (yenestock_movements):
- id: INT PRIMARY KEY
- itemId: INT (indexed)
- locationId: INT (indexed)
- movementType: ENUM (indexed)
- quantity: DECIMAL(15,2)
- beforeQuantity: DECIMAL(15,2)
- afterQuantity: DECIMAL(15,2)
- referenceNo: VARCHAR
- fromLocationId: INT
- toLocationId: INT
- reason: TEXT
- createdBy: INT
- approvedBy: INT
- approvedAt: TIMESTAMP
- isApproved: BOOLEAN
- createdAt: TIMESTAMP (indexed)

HOW TO USE
================================================================================

ACCESS YENESTOCK:
1. Login as admin user
2. Look for "🏭 YeneStock" in sidebar
3. Click to expand submenu
4. Choose desired page

CREATE FIRST WAREHOUSE:
1. Go to Warehouse Locations
2. Click "➕ Add Location"
3. Fill in warehouse details
4. Click "Add Location"

CREATE INVENTORY:
1. Go to Inventory Overview
2. Click "View Details" on existing items or
3. Use API to create: POST /yenestock/inventory

RECORD STOCK MOVEMENT:
1. Use API: POST /yenestock/movements
2. Specify: itemId, locationId, movementType, quantity

MONITOR ALERTS:
1. Go to Stock Alerts page
2. Filter by severity or type
3. Click "View" for details
4. Take action on critical alerts

GENERATE REPORTS:
1. Go to Reports & Analytics
2. Select report type
3. Choose date range
4. Click "📥 Export PDF" to download

QUICK START COMMANDS
================================================================================

FRONTEND - VIEW INVENTORY:
Browser: http://localhost:3000/yenestock

CREATE LOCATION (API):
curl -X POST http://localhost:3001/yenestock/locations \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"code":"WH001","warehouseName":"Main","city":"Addis Ababa"}'

CREATE INVENTORY (API):
curl -X POST http://localhost:3001/yenestock/inventory \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"itemId":1,"locationId":1,"currentQuantity":100,"minimumLevel":10}'

RECORD MOVEMENT (API):
curl -X POST http://localhost:3001/yenestock/movements \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"itemId":1,"locationId":1,"movementType":"INBOUND","quantity":50}'

GET SUMMARY (API):
curl http://localhost:3001/yenestock/analytics/summary \
  -H "Authorization: Bearer TOKEN"
