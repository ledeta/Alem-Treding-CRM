🔧 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. USER CREATES REQUEST IN SALES
   Sales → Create Request → Fill Form → Submit
   ↓
   Request saved to localStorage['payment_requests']

2. ADMIN OPENS APPROVALS PAGE
   Admin → Approvals
   ↓
   Page loads and:
   - Fetches MOCK_APPROVALS (mock data)
   - Fetches payment_requests (user created)
   - Converts payment_requests to Approval format
   - Merges both arrays
   - Displays combined list

3. ADMIN MANAGES REQUESTS
   - Approve: Change status to "Approved" ✅
   - Reject: Change status to "Rejected" ❌
   - Filter: By Status, Type, or Search keyword
   - View: Full details in modal
   ↓
   All changes persist to localStorage
