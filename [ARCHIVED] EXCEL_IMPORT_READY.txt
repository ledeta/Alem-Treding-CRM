📋 EXCEL FILE REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════════

Required Columns:
  • Customer Name - (auto-creates if not exists)
  • Item Name - (auto-creates with category detection)
  • Quantity - (positive number)
  • Selling Price - (positive number)
  • Sold By - (matches user; uses current user if not found)
  • Branch - ("Warehouse" or "Shop")
  • Date - (optional; defaults to today)

Optional Columns:
  • Discount - (number >= 0)
  • Tax - (number >= 0)
  • Notes - (text)

The system automatically detects columns by name variations.
Example: "qty", "quantity", "units" all recognized as Quantity.

🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

For Sales Users:
  1. Go to: http://localhost:3000/sales/upload
  2. Prepare Excel file with required columns
  3. Drag-drop or click to upload
  4. Review preview and summaries
  5. Done! Transactions auto-created with stock updated

For Admin Users:
  1. Go to: http://localhost:3000/admin/uploads
  2. Follow same steps as Sales Users
  3. Can import for multiple salespeople
