🔧 HOW TO CREATE YOUR OWN EXCEL FILE
═════════════════════════════════════════════════════════════════════════════

Required Columns (in this exact order):
1. Customer Name      - Name of the buyer (string)
2. Item Name          - Product name (string)
3. Quantity           - Units sold (number)
4. Selling Price      - Price per unit (number)
5. Sold By            - Salesperson username (string)
6. Branch             - MUST be "Warehouse" or "Shop" (string)
7. Date               - Transaction date YYYY-MM-DD (string)

Optional Columns:
8. Discount           - Discount amount (number, optional)
9. Tax                - Tax amount (number, optional)
10. Notes             - Any notes (string, optional)

Example Format:
┌─────────────────────────────────────────────────────────────────────────┐
│ Customer Name | Item Name | Quantity | Selling Price | Sold By | Branch │
├─────────────────────────────────────────────────────────────────────────┤
│ John Doe      │ Rice      │ 50       │ 85           │ sales   │ Shop   │
│ Jane Smith    │ Milk      │ 30       │ 120          │ sales   │ Whouse │
└─────────────────────────────────────────────────────────────────────────┘

IMPORTANT NOTES:
• Branch MUST be exactly "Warehouse" or "Shop" (case-sensitive)
• Sold By should match a valid username (e.g., "sales", "admin")
• Date should be in YYYY-MM-DD format
• Quantity and Selling Price must be numbers (not text)

❓ FREQUENTLY ASKED QUESTIONS
═════════════════════════════════════════════════════════════════════════════

Q: What happens to existing customers/items?
A: If customer or item already exists, it's reused
   New ones are auto-created from the Excel data

Q: How are items categorized?
A: System scans item names for keywords:
   - "rice", "wheat", "corn" → Grains & Cereals
   - "milk", "cheese", "yogurt" → Dairy
   - "oil", "ghee", "butter" → Oils & Fats
   - "bean", "lentil", "pea" → Legumes
   - "spice", "salt", "pepper" → Spices
   - "vegetable", "tomato", "onion" → Vegetables
   - "fruit", "apple", "banana" → Fruits
   - "bread", "flour" → Bakery
   - "tea", "coffee", "juice" → Beverages
   - Anything else → General

Q: What if an item doesn't match any category?
A: It's placed in "General" category
   You can update the category manually later

Q: Can I upload the same file twice?
A: Yes, but it will create duplicate transactions
   Use "Clear History" to start fresh, or manually review

Q: What's the maximum file size?
A: Up to 10MB Excel files are supported

Q: Can I upload from Admin section too?
A: Yes! Admin has http://localhost:3000/admin/uploads
   Same features, admin-level access

Q: How do I know if the import succeeded?
A: Check the green "Completed" status
   View detailed results breakdown
   Go to Transactions page to verify data

⚠️ TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Issue: Upload shows "Failed"
Fix: 
  1. Check Excel file format (.xlsx or .xls only)
  2. Verify all required columns present
  3. Ensure no blank rows in the middle
  4. Check Branch values are exactly "Warehouse" or "Shop"
  5. See browser console (F12) for detailed errors

Issue: File won't upload
Fix:
  1. Clear browser cache (F12 → Application → Clear)
  2. Refresh page and try again
  3. Try different browser
  4. Verify file isn't corrupted

Issue: Items categorized incorrectly
Fix:
  1. Edit item manually in Items page
  2. Change category to correct one
  3. Save changes

Issue: Customers created but not visible
Fix:
  1. Go to http://localhost:3000/customers
  2. Search for customer by name
  3. May need to refresh or scroll

Issue: Can't see transactions in list
Fix:
  1. Go to http://localhost:3000/transactions
  2. Scroll down or use search
  3. Filter by date if needed
