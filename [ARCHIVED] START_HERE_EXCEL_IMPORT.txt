📋 EXCEL FILE REQUIREMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Your Excel file needs these columns:

  REQUIRED:
    • Customer Name ........... Name of customer (auto-creates if missing)
    • Item Name ............... Product name (auto-creates with category)
    • Quantity ................ Number of units (must be > 0)
    • Selling Price ........... Price per unit (must be > 0)
    • Sold By ................. Salesperson name
    • Branch .................. "Warehouse" or "Shop"

  OPTIONAL:
    • Date .................... Transaction date (defaults to today)
    • Discount ................ Discount amount
    • Tax ..................... Tax amount
    • Notes ................... Any notes

The system automatically detects your columns by name patterns.
For example, "qty", "quantity", "amount" are all recognized as Quantity.

✨ WHAT IT DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  - Details of any errors
✓ Keeps upload history in your browser
✓ Shows detailed preview of imported data

Problem: "File won't upload"
Solution: Check if file is .xlsx or .xls format

Problem: "Column not found" error
Solution: Make sure Excel has required columns with proper names

Problem: "Branch not recognized"
Solution: Use exactly "Warehouse" or "Shop" (case matters)

Problem: "Quantity must be positive" error
Solution: Make sure quantity and price are positive numbers

For more issues, see EXCEL_IMPORT_IMPLEMENTATION.md "Troubleshooting" section
