TROUBLESHOOTING
================================================================================

"Repository not found"
→ Check token is valid (hasn't expired)
→ Regenerate at: https://github.com/settings/tokens

"Permission denied"  
→ Token doesn't have correct scopes
→ Regenerate with: repo + admin:repo_hook scopes

"Already exists" error
→ Repository already created, just pushing code
→ Script handles this automatically

"Execution policy" error
→ Run: Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser
