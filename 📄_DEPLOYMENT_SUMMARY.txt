================================================================================
TROUBLESHOOTING
================================================================================

Build fails?
   → Check Render logs for error details
   → Verify Node version compatibility
   → Ensure all dependencies in package.json

App won't start?
   → Check environment variables are set
   → Verify start script in package.json
   → Try manual deploy from Render dashboard

Page is blank?
   → Hard refresh: Ctrl + Shift + Delete (Windows)
   → Clear browser cache
   → Check browser console for errors

API calls fail (expected)?
   → This is normal - backend not deployed
   → Data will use localStorage for now
   → Backend integration comes later
