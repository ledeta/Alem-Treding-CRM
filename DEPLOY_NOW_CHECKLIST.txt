☐ STEP 4: Deploy Backend Service
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Go to: https://dashboard.render.com
  2. Click: New + → Web Service
  3. Select: https://github.com/miliyee/Alem-Treding
  4. Set Name: alem-crm-backend
  5. Set Build Command:
     cd backend && npm install && npm run build
  6. Set Start Command:
     cd backend && npm run start:prod
  7. Add Environment Variables:
     • NODE_ENV = production
     • DATABASE_URL = postgresql://alem_user:PASSWORD@localhost:5432/alem_crm
     • JWT_SECRET = your-secure-secret-key
     • JWT_EXPIRATION = 7d
     • PORT = 3001
     • CORS_ORIGIN = https://alem-crm-frontend.onrender.com (update later)
     • LOG_LEVEL = info
  8. Click: Create Web Service
  9. Wait: 3-5 minutes for build
  10. Note: Backend URL when ready (e.g., https://alem-crm-backend.onrender.com)

TROUBLESHOOTING
================================================================================

If you see ERRORS:
1. Check Render → Service → Logs
2. Look for specific error message
3. Common issues:
   - 504 Timeout: Backend not running, check logs
   - CORS Error: Verify CORS_ORIGIN matches frontend URL
   - 401 Unauthorized: Check JWT_SECRET is set
   - Blank Page: Check NEXT_PUBLIC_API_URL is correct

Need to Redeploy?
1. Make changes locally
2. git add .
3. git commit -m "Your message"
4. git push origin main
5. Render automatically redeploys
