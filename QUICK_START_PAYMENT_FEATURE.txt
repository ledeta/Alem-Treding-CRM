HOW TO TEST:
─────────────────────────────────────────────────────────────────────────

1. START THE SYSTEM:
   ✓ Backend: Already running on port 3001
   ✓ Frontend: Already running on port 3000
   ✓ Database: PostgreSQL connected

2. OPEN IN BROWSER:
   http://localhost:3000/sales/customer-search

3. SELECT A CUSTOMER:
   - Method A: Type name in search box and click Search
   - Method B: Click on any customer card in the list below

4. CLICK "CREATE PAYMENT REQUEST":
   - A modal dialog will open

5. FILL THE FORM:
   - Amount: Enter payment amount (e.g., 5000)
   - Select Bank: Choose from dropdown (Telebirr, Sinqqee, Cash, etc.)
   - Reason: Enter payment reason
   - Date & Time: Pick a date and time
   - Description: Optional notes

6. CLICK "SUBMIT REQUEST":
   - You'll see: "Payment request created for [Customer Name]!"
   - Modal closes automatically
   - Payment request saved to database

TROUBLESHOOTING:
─────────────────────────────────────────────────────────────────────────

Problem: Modal doesn't open
→ Solution: Hard refresh page (Ctrl+Shift+R) and try again

Problem: Can't select bank
→ Solution: Click directly on dropdown, wait for options to show

Problem: Form shows "Please enter [field]" after filling
→ Solution: Check field is filled properly, empty fields show alerts

Problem: "Failed to create payment request" message
→ Solution: Check backend is running (should see it in terminal)

Problem: Page shows error on customer search
→ Solution: Hard refresh (Ctrl+Shift+R) to clear Next.js cache

API ENDPOINT:
─────────────────────────────────────────────────────────────────────────

POST /api/payments

Example using curl:
──────────────────
curl -X POST http://localhost:3001/api/payments \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": 1,
    "amount": 5000,
    "bank": "Telebirr",
    "reason": "Payment for goods",
    "requestDate": "2024-07-30T15:00:00Z"
  }'

Response (201 Created):
──────────────────────
{
  "id": 1,
  "amount": "5000.00",
  "bank": "Telebirr",
  "reason": "Payment for goods",
  "status": "Pending",
  "createdAt": "2024-07-30T15:00:00.000Z"
}
