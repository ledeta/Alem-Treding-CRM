================================================================================
                        SKU AUTO-GENERATION
================================================================================

Logic:
  New Item ID = Max existing ID + 1
  New SKU = "ITEM" + ID (padded to 3 digits)

Examples:
  If 2 items exist:
  - New item gets ID: 3
  - Auto SKU: ITEM003

  If 9 items exist:
  - New item gets ID: 10
  - Auto SKU: ITEM010

  If 99 items exist:
  - New item gets ID: 100
  - Auto SKU: ITEM100

Consistency:
  ✅ No duplicate SKUs possible
  ✅ All SKUs follow same format
  ✅ Easy to identify items by SKU
  ✅ System generated, always valid
