STEP 3: RENDER.COM DEPLOYMENT SETUP

A. CREATE DATABASE (PostgreSQL)
   1. Go to https://dashboard.render.com/
   2. Click "New +" → "PostgreSQL"
   3. Name: alem-postgres
   4. Database: alem_crm
   5. User: postgres
   6. Region: Frankfurt (or closest to you)
   7. Plan: Standard
   8. Create
   9. Copy the "Internal Database URL" - use for DATABASE_URL

B. CREATE CACHE (Redis)
   1. Click "New +" → "Redis"
   2. Name: alem-redis
   3. Region: Same as database
   4. Plan: Starter
   5. Create
   6. Copy the "Redis URL" - use for REDIS_URL

C. DEPLOY BACKEND SERVICE
   1. Click "New +" → "Web Service"
   2. Choose "Deploy existing repository"
   3. Paste GitHub URL: https://github.com/miliyee/Alem-Treding
   4. Configuration:
      - Name: alem-crm-backend
      - Environment: Node
      - Build Command: npm run build
      - Start Command: npm run start
      - Region: Same as database
      - Plan: Starter or Standard
   5. Add Environment Variables (from BACKEND SERVICE VARIABLES above)
   6. Click "Create Web Service"
   7. Wait for deployment (5-10 minutes)
   8. Copy the Backend URL when ready

D. DEPLOY FRONTEND SERVICE
   1. Click "New +" → "Web Service"
   2. Choose "Deploy existing repository"
   3. Paste GitHub URL: https://github.com/miliyee/Alem-Treding
   4. Configuration:
      - Name: alem-crm-frontend
      - Environment: Node
      - Build Command: npm run build
      - Start Command: npm run start
      - Region: Same as backend
      - Plan: Starter or Standard
   5. Add Environment Variables:
      - Use FRONTEND SERVICE VARIABLES above
      - Replace backend URL with your actual backend service URL
   6. Click "Create Web Service"
   7. Wait for deployment

IMPORTANT NOTES:
================

✓ All secrets (JWT_SECRET, etc.) should be:
  - At least 20 characters long
  - Random and unique
  - Different from development values

✓ Database URL format:
  postgres://user:password@host:port/database

✓ Redis URL format:
  redis://:password@host:port/0

✓ After backend deploys, copy its URL and update frontend's:
  NEXT_PUBLIC_API_URL=<your_backend_url>

✓ Service names will be something like:
  - alem-crm-backend.onrender.com
  - alem-crm-frontend.onrender.com

✓ First deployment takes 5-15 minutes. Check logs if stuck.

✓ If deployment fails, check:
  1. Environment variables are set correctly
  2. Database is running
  3. Build logs for TypeScript errors
  4. Commit files to GitHub (backend/ and frontend/ directories)


TROUBLESHOOTING:
================

Build fails with "Cannot find module":
  → Run: npm install in backend and frontend directories
  → Commit package-lock.json to GitHub

Port 3001 already in use:
  → Change PORT env var in backend
  → Update NEXT_PUBLIC_API_URL in frontend

Cannot connect to database:
  → Verify DATABASE_URL is correct
  → Check database is running in Render
  → Verify credentials match

Frontend shows 404:
  → Clear browser cache (Ctrl+Shift+Del)
  → Check build logs completed successfully
  → Verify NEXT_PUBLIC_API_URL is correct
