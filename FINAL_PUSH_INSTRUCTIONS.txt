GitHub CLI is now installed! Follow these steps:

STEP 1: Authenticate with GitHub
================================================================================
Run this command:

gh auth login --web

This will:
1. Open your browser
2. Ask you to authorize GitHub CLI
3. Generate a code to paste
4. Complete authentication

Just follow the prompts in your browser.


STEP 2: Create Repository and Push (After Authentication)
================================================================================
Run these commands:

$env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")
cd "C:\Users\Milion's\Desktop\Alem-Treding-main"

# Create the repository
gh repo create Alem-Tredint --public --source=. --remote=origin --push

Done! Your code will be pushed to: https://github.com/ledeta/Alem-Tredint

TROUBLESHOOTING
================================================================================

"Command not found: gh"
→ Restart PowerShell completely (close and reopen)
→ Then try again

"Not authenticated"
→ Run: gh auth login --web
→ Follow browser prompts

"Repository already exists"
→ That's OK, just run the push commands

"Permission denied"
→ Make sure you authorized GitHub CLI in the browser
