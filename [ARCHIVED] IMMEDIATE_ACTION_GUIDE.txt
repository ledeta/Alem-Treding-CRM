🛠️ IF SOMETHING GOES WRONG
================================================================================

PROBLEM: Blank page or 404 errors
───────────────────────────────────
Solution:
1. Press Ctrl+Shift+Delete (Clear cache)
2. Refresh page (Ctrl+R)
3. Try incognito window (Ctrl+Shift+N)

PROBLEM: Can't login
──────────────────────
Solution:
1. Check backend is running (Process [18])
2. Test: curl http://localhost:3001/health
3. Verify database running: psql -U postgres -d alem_crm
4. Check credentials are correct

PROBLEM: YeneStock menu missing
────────────────────────────────
Solution:
1. Refresh page (Ctrl+R)
2. Clear cache (Ctrl+Shift+Delete)
3. Check sidebar component updated
4. Verify backend seeding completed

PROBLEM: Real-time data not updating
──────────────────────────────────────
Solution:
1. Check WebSocket connection (F12 → Network → WS)
2. Refresh page
3. Check backend logs for errors
4. Verify socket.service.ts configuration

PROBLEM: API returning errors
──────────────────────────────
Solution:
1. Test in Postman: GET http://localhost:3001/api/yenestock/inventory
2. Check response status (should be 200)
3. Review backend logs for errors
4. Verify authentication token included
