OPTION 1: RUN LOCALLY (15 minutes) - START HERE
================================================================================

This lets you test the application on your machine first.

Prerequisites:
✓ Node.js 20+ installed (https://nodejs.org)
✓ PostgreSQL installed (https://www.postgresql.org)

Steps:

1. BACKEND SETUP
   cd backend
   cp .env.example .env
   Edit .env with database credentials
   npm install
   npm run build
   npm run start:prod

2. FRONTEND SETUP (open new PowerShell window)
   cd frontend
   cp .env.example .env.local
   Edit .env.local - set: NEXT_PUBLIC_API_URL=http://localhost:3001
   npm install
   npm run build
   npm start

3. ACCESS APPLICATION
   Frontend: http://localhost:3000
   Backend: http://localhost:3001

4. LOGIN & TEST
   Email: million
   Password 1: million123
   Password 2: million456

5. VERIFY
   ✓ Dashboard loads
   ✓ Users page accessible
   ✓ Can create users
   ✓ Permissions show


OPTION 2: RUN IN DOCKER (10 minutes)
================================================================================

This uses Docker containers (more portable).

Prerequisites:
✓ Docker Desktop installed (https://www.docker.com/products/docker-desktop)

Steps:

1. BUILD IMAGES
   docker build -t alem-frontend ./frontend
   docker build -t alem-backend ./backend

2. RUN CONTAINERS
   docker run -d -p 3000:3000 --name frontend alem-frontend
   docker run -d -p 3001:3001 --name backend alem-backend

3. ACCESS
   Frontend: http://localhost:3000
   Backend: http://localhost:3001

4. TEST
   Same as Option 1 - use test credentials above


OPTION 3: DEPLOY TO RENDER (20 minutes)
================================================================================

This deploys to the internet (live deployment).

Prerequisites:
✓ GitHub account (https://github.com - free)
✓ Render account (https://render.com - free tier available)

Steps:

1. CREATE GITHUB REPOSITORY
   Go to: https://github.com/new
   Name: Alem-Tredint
   Visibility: Public
   Click: Create repository

2. CREATE GITHUB TOKEN
   Go to: https://github.com/settings/tokens
   Generate new token (classic)
   Scope: repo
   Copy token

3. PUSH CODE
   Open PowerShell in project directory:
   
   $token = "YOUR_TOKEN_HERE"
   cd "C:\Users\Milion's\Desktop\Alem-Treding-main"
   git remote remove origin
   git remote add origin "https://ledeta:$token@github.com/ledeta/Alem-Tredint.git"
   git push -u origin main --force

4. DEPLOY ON RENDER
   Go to: https://render.com
   Sign up with GitHub
   Connect repository: ledeta/Alem-Tredint
   
   Create PostgreSQL database:
   - Name: alem-crm-db
   - Database: alem_crm
   - Plan: Standard ($15/mo)
   
   Create Backend Service:
   - Name: alem-crm-backend
   - Dockerfile: ./backend/Dockerfile
   - Add environment variables (see RENDER_FULL_ENVIRONMENT_SETUP.md)
   
   Create Frontend Service:
   - Name: alem-crm-frontend
   - Dockerfile: ./frontend/Dockerfile
   - Add environment variables (see RENDER_FULL_ENVIRONMENT_SETUP.md)

5. ACCESS LIVE APPLICATION
   Frontend: https://alem-crm-frontend.onrender.com
   Backend: https://alem-crm-backend.onrender.com/api

6. TEST
   Login with test credentials (same as Option 1)
