                            STEP-BY-STEP GUIDE
═══════════════════════════════════════════════════════════════════════════════

1️⃣  GO TO RENDER.COM
    └─ Visit: https://render.com
    └─ Sign up or log in (use GitHub account for easy setup)

2️⃣  CREATE NEW WEB SERVICE
    └─ Click: "+ New" button
    └─ Select: "Web Service"
    └─ Choose: "Build and deploy from a Git repository"

3️⃣  CONNECT YOUR GITHUB REPOSITORY
    └─ Click: "Connect" next to GitHub account
    └─ Search for: "Alem-Treding"
    └─ Click: Select your repository
    └─ Click: "Connect"

4️⃣  CONFIGURE THE SERVICE
    
    Name:
    ├─ alem-crm-frontend
    │  (or any name you prefer)
    
    Environment:
    ├─ Node
    
    Region:
    ├─ Select closest to you (e.g., Ohio for US, EU for Europe)
    
    Branch:
    ├─ main
    
    Build Command:
    ├─ npm install && npm run build
    
    Start Command:
    ├─ npm run start
    
    Instance Type:
    ├─ Free (for testing/demo)

5️⃣  ADD ENVIRONMENT VARIABLES
    
    In the "Environment" section, add:
    
    Key 1:
    ├─ NODE_ENV
    └─ Value: production
    
    Key 2:
    ├─ NEXT_PUBLIC_API_URL
    └─ Value: https://alem-crm-frontend.onrender.com
       (Replace "alem-crm-frontend" with your actual service name)

6️⃣  CREATE AND DEPLOY
    └─ Click: "Create Web Service"
    └─ Wait: Build starts automatically (2-5 minutes)
    └─ Watch: Logs display in real-time
    └─ Success: Green "Live" badge appears

7️⃣  VERIFY DEPLOYMENT
    └─ Click the URL shown (or find in Service name)
    └─ App opens in new tab: https://[your-service-name].onrender.com
    └─ Test login with credentials below

8️⃣  TEST YOUR APP
    
    Admin Login:
    ├─ Username: admin
    ├─ Password 1: Admin@2024!
    ├─ Password 2: AdminSecure#2024
    └─ Then explore: Admin → Approvals
    
    Sales Login:
    ├─ Username: sales
    ├─ Password 1: Sales@2024!
    ├─ Password 2: SalesSecure#2024
    └─ Then explore: Sales → Upload, Sales → Create Request

═══════════════════════════════════════════════════════════════════════════════
                         TROUBLESHOOTING QUICK TIPS
═══════════════════════════════════════════════════════════════════════════════

Build Fails:
  └─ Check the logs in Render dashboard
  └─ Ensure package.json has all dependencies
  └─ Try clicking "Redeploy" to retry

Page Shows Blank:
  └─ Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
  └─ Check browser console (F12 → Console tab)
  └─ Check Render logs for errors

Login Doesn't Work:
  └─ Make sure you're using correct credentials (see above)
  └─ Check if localStorage is enabled in browser
  └─ Try incognito window (Ctrl+Shift+N)

App is Slow/Paused:
  └─ Normal on free tier - service pauses after 15 min inactivity
  └─ Will wake up automatically when accessed
  └─ Takes 30-60 seconds to start
