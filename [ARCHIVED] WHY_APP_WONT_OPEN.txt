🚀 START POSTGRESQL:

   Option 1: Using Command Prompt
   ────────────────────────────────
   1. Open Command Prompt (cmd)
   2. Run this command:
      pg_ctl -D "C:\Program Files\PostgreSQL\18\data" start
   
   3. Press Enter
   4. Wait for success message
   5. Done! Database is running

   Option 2: Using Windows Services
   ────────────────────────────────
   1. Right-click Start button
   2. Select "Services"
   3. Find "postgresql-x64-18"
   4. Right-click it
   5. Click "Start"
   6. Done! Database is running

   Option 3: Using Batch File
   ──────────────────────────
   1. Look in your project root for: START_POSTGRESQL.bat
   2. Double-click it
   3. Wait for message
   4. Done! Database is running
