## 🆘 TROUBLESHOOTING

### BlueStacks Won't Install
**Issue**: Installation fails or freezes
**Solutions**:
- Check Windows is updated
- Disable antivirus temporarily
- Download offline installer if needed
- Ensure virtualization enabled in BIOS

### BlueStacks Won't Start
**Issue**: Emulator won't launch
**Solutions**:
- Restart computer
- Uninstall and reinstall
- Check system requirements
- Enable Intel VT or AMD-V in BIOS

### APK Won't Install
**Issue**: Installation fails
**Solutions**:
- Check file is 4.1 MB
- Try drag & drop method
- Check file isn't corrupted
- Try again

### App Won't Launch
**Issue**: App crashes on startup
**Solutions**:
- Check backend is running
- Wait 30 seconds after install
- Clear BlueStacks cache
- Uninstall and reinstall app

### Login Fails
**Issue**: Authentication error
**Solutions**:
- Verify credentials exactly:
  - admin (lowercase)
  - Admin@2024! (with !)
  - AdminSecure#2024 (with #)
- Clear app cache
- Try again

### Backend Connection Error
**Issue**: App can't reach backend
**Solutions**:
- Check http://localhost:3001 on your PC
- Backend may be on 10.0.2.2 in BlueStacks
- Restart backend server
- Check firewall isn't blocking
