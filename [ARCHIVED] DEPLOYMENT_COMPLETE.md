## 🚀 How to Deploy (Quick Summary)

### 6 Simple Steps

1. **Create Render Account** (5 min)
   - Go to https://render.com
   - Sign up with GitHub
   - Authorize Render app

2. **Connect GitHub** (2 min)
   - Click "New +"
   - Select "Web Service"
   - Connect "Alem-Treding" repository

3. **Configure Service** (3 min)
   - Name: alem-crm
   - Build: `cd frontend && npm install && npm run build`
   - Start: `cd frontend && npm start`
   - Instance: Free

4. **Deploy** (10 min)
   - Click "Deploy Web Service"
   - Watch logs for "Live" status
   - Render builds and starts automatically

5. **Get URL** (1 min)
   - Your URL appears in dashboard
   - Example: https://alem-crm.onrender.com

6. **Test App** (5 min)
   - Open your URL
   - Login with admin credentials
   - Verify features work

**Total Time: ~26 minutes**
