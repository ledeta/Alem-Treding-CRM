🎯 THE 5-STEP BUILD PROCESS

1️⃣  BUILD FRONTEND
    cd frontend
    npm run build
    cd ../android-app

2️⃣  INITIALIZE CAPACITOR
    npx cap init
    (Choose defaults, use com.alemtrading.crm as package ID)

3️⃣  ADD ANDROID PLATFORM
    npx cap add android
    npx cap sync android

4️⃣  OPEN IN ANDROID STUDIO
    npx cap open android

5️⃣  BUILD APK
    In Android Studio: Build → Build APK(s)

⚠️ IMPORTANT REMINDERS

1. INSTALL PREREQUISITES FIRST
   → Cannot build without JDK and Android Studio

2. SET ENVIRONMENT VARIABLES
   → JAVA_HOME and ANDROID_HOME must be set correctly
   → Restart terminal/IDE after setting

3. BUILD FRONTEND EACH TIME
   → Run "npm run build" before syncing to Android
   → Capacitor copies from frontend/out

4. BACKUP SIGNING KEYSTORE
   → Save keystore password securely
   → Losing it = cannot update on Play Store

5. CHECK API CONNECTIVITY
   → App connects to https://alem-crm-api.onrender.com
   → Verify backend is accessible before testing
