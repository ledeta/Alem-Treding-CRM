HOW IT WORKS IN 3 STEPS

1️⃣  USER CREATES REQUEST
    Sales → Create Request → (Payment/Credit/Refund) → Submit
    ↓ Saved to localStorage

2️⃣  ADMIN SEES REQUEST
    Admin → Approvals → Page loads → ✨ Request appears in table!
    ↓ With all details

3️⃣  ADMIN MANAGES REQUEST
    Click "✓ Approve" or "✕ Reject" → Status changes → ✅ Persists

                            ↓
