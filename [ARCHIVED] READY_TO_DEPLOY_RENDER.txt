DEPLOYMENT INSTRUCTIONS FOR RENDER:
───────────────────────────────────────────────────────────────────────────

STEP 1: Deploy Backend Service
────────────────────────────────
1. Go to: https://dashboard.render.com
2. Click "+ New" → "Web Service"
3. Select repository: Alem-Treding
4. Configure:
   - Name: alem-crm-backend
   - Root Directory: backend
   - Build Command: npm install && npm run build
   - Start Command: node dist/main.js

5. Environment Variables:
   NODE_ENV=production
   PORT=3001
   DATABASE_URL=postgresql://[user]:[pass]@[host]:[port]/alem_crm
   JWT_SECRET=[generate random string]

6. Click "Create Web Service"
7. Wait 5-10 minutes for deployment
8. Copy the backend URL (e.g., https://alem-crm-backend.onrender.com)

STEP 2: Deploy Frontend Service
─────────────────────────────────
1. Click "+ New" → "Web Service"
2. Select repository: Alem-Treding
3. Configure:
   - Name: alem-crm-frontend
   - Root Directory: frontend
   - Build Command: npm install && npm run build
   - Start Command: npm run start

4. Environment Variables:
   NODE_ENV=production
   NEXT_PUBLIC_API_URL=https://alem-crm-backend.onrender.com/api

5. Click "Create Web Service"
6. Wait 5-10 minutes for deployment
7. Copy the frontend URL (e.g., https://alem-crm-frontend.onrender.com)

STEP 3: Create PostgreSQL Database
───────────────────────────────────
1. Click "+ New" → "PostgreSQL"
2. Configure:
   - Name: alem-crm-db
   - Database Name: alem_crm
   - User: [create username]
   - Password: [create secure password]

3. Get connection details
4. Update backend environment variables with DATABASE_URL
5. Database automatically backs up daily

STEP 4: Verify Deployment
──────────────────────────
Test these endpoints:

Health Check:
  curl https://alem-crm-backend.onrender.com/api/health
  Expected: 200 OK

Customers:
  curl https://alem-crm-backend.onrender.com/api/customers?page=1&limit=5
  Expected: 200 OK with customer list

Frontend:
  Visit: https://alem-crm-frontend.onrender.com
  Expected: Home page loads

SUPPORT & TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────────────

If Backend Fails to Start:
  1. Check environment variables are set
  2. Verify DATABASE_URL is correct
  3. Check PostgreSQL service is running
  4. Review Render logs for error messages
  5. See RENDER_DEPLOYMENT_GUIDE.md Troubleshooting

If Frontend Can't Connect:
  1. Verify NEXT_PUBLIC_API_URL is correct
  2. Test backend /api/health endpoint
  3. Check CORS is enabled
  4. Clear browser cache
  5. See RENDER_DEPLOYMENT_GUIDE.md Troubleshooting

If Payment Feature Doesn't Work:
  1. Verify backend is running
  2. Check @Public() decorator is applied
  3. Verify payment_requests table exists
  4. Check database connectivity
  5. Review browser console errors
