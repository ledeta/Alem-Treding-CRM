───────────────────────────────────────────────────────────────────────────────
API ENDPOINTS
───────────────────────────────────────────────────────────────────────────────

PUBLIC ENDPOINTS (No Auth Required):

GET /api/customers
  Returns: List of all customers with pagination

GET /api/customers/search?q=name&field=name
  Returns: Customers matching search query

GET /api/items?page=1&limit=999
  Returns: All items with stock information

GET /api/transactions/by-customer/{id}
  Returns: Transactions for specific customer

GET /api/transactions/by-item/{id}
  Returns: Transactions for specific item

PROTECTED ENDPOINTS (JWT Required):

POST /api/customers
  Create new customer

POST /api/items
  Create new item

POST /api/transactions/import/sales
  Import transactions from Excel
