🔍 DEBUGGING TIPS
═══════════════════════════════════════════════════════════════════════════════

Check Browser Console:
1. Open DevTools (F12)
2. Go to Console tab
3. Look for Socket.io connection logs:
   [Socket.io] Chat Connected to /chat
   [Socket.io] Notifications Connected to /notifications

If you see connection errors:
→ Check backend is running on port 3001
→ Check NEXT_PUBLIC_API_URL=http://localhost:3001 in .env.local
→ Check CORS is enabled (should be by default)
→ Clear browser cache and refresh

Check Network Tab:
1. Go to Network tab in DevTools
2. Look for WebSocket connections
3. Should see:
   • ws://localhost:3001/socket.io (chat)
   • ws://localhost:3001/socket.io (notifications)
   • ws://localhost:3001/socket.io (dashboard)

Check Server Logs:
1. In backend terminal, look for:
   "Chat Gateway initialized"
   "Notifications Gateway initialized"
   "Dashboard Gateway initialized"
   "User X connected"
   "User X joined conversation"

🐛 COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════════════════

Issue 1: "Cannot connect to WebSocket"
Fix:
  1. Ensure backend is running: npm run start:dev
  2. Check port 3001 is not blocked
  3. Verify firewall allows localhost:3001
  4. Clear browser cache and try again
  5. Check backend logs for errors

Issue 2: "Messages not appearing in real-time"
Fix:
  1. Check browser console for errors
  2. Verify Socket.io connection status
  3. Try sending from different browser window
  4. Check backend is receiving send_message event
  5. Verify database is accessible

Issue 3: "Notifications not showing"
Fix:
  1. Check notifications socket is connected
  2. Verify user ID is correct
  3. Check if notifications are being created in DB
  4. Try triggering notification manually
  5. Check browser notifications permission

Issue 4: "Dashboard not updating"
Fix:
  1. Check dashboard socket connection
  2. Verify 30-second interval is working
  3. Click refresh button to force update
  4. Check if backend data is changing
  5. Verify timestamp is updating

Issue 5: "Frequent disconnections"
Fix:
  1. Check network stability
  2. Verify backend is responsive
  3. Check for errors in browser console
  4. Look for memory leaks
  5. Try disabling browser extensions
