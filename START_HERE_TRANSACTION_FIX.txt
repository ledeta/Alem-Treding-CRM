HOW TO USE REAL DATA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Create Excel File
  
  Create a file (e.g., transactions.xlsx) with columns:
  
  | Customer Name | Item Name      | Qty | Price | Sold By     | Branch       | Date       |
  |---|---|---|---|---|---|---|
  | Mame Negele   | SM LI plus s10 | 2   | 1000  | Mame Negele | Warehouse 1  | 2026-07-15 |
  | Mame Negele   | Oppo Reno 7 4g | 7   | 5000  | Mame Negele | Warehouse 1  | 2026-07-15 |
  | Hassan Ahmed  | iPhone 13      | 1   | 15000 | Mame Negele | Shop 1       | 2026-08-01 |

STEP 2: Upload to System
  
  In Sales Dashboard:
  1. Look for "Import Sales Transactions & Items" section (orange theme)
  2. Click "📦 Upload Transactions"
  3. Select your Excel file
  4. See ✅ "Successfully imported X transactions"

STEP 3: View in Customer Profile
  
  1. Click on a customer (name must match Excel file)
  2. See their items in "Items Purchased" section
  3. All items and details display from database
  4. Prices and totals calculated correctly

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❓ Items not showing?
  • Make sure customer name in Excel EXACTLY matches database
  • Upload customers first (if not already imported)
  • Then upload transactions
  • Refresh browser (Ctrl+F5)

❓ Upload failed?
  • Check Excel columns: Customer Name, Item Name, Qty, Price, Sold By, Branch, Date
  • Make sure numeric fields are numbers, not text
  • Try sample file format from TRANSACTION_IMPORT_GUIDE.md

❓ No transactions to import?
  • Start with sample data from QUICK_START_TRANSACTIONS.txt
  • Or follow example in TRANSACTION_IMPORT_GUIDE.md
