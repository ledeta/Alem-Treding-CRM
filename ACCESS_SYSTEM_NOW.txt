================================================================================
                    TROUBLESHOOTING
================================================================================

Issue: "Cannot connect to backend"
→ Wait 15 more seconds and refresh browser
→ Check that backend has fully started

Issue: "Login failed"
→ Check email/password are exactly correct
→ Clear browser cache (Ctrl+Shift+Delete)
→ Refresh and try again

Issue: "Blank page"
→ Open DevTools console (F12)
→ Check for JavaScript errors
→ Refresh page

Issue: "Navigation buttons not showing"
→ Page didn't fully load
→ Refresh browser
→ Check backend is running
